# awg-manager: AmneziaWG 3.1 (TSPU-Stealth & Hardened Standard VPN)

Надёжный установщик и менеджер **AmneziaWG 3.1** (нативный модуль ядра `amneziawg.ko`) для Ubuntu 24.04 LTS с усиленной защитой от ТСПУ/DPI, стандартным полным туннелем (`AllowedIPs = 0.0.0.0/0`) и защищённым Telegram-ботом управления.

> **Только стандартный полный туннель:** весь трафик клиентов направляется через VPN (`0.0.0.0/0`) без split-tunneling, GeoIP-обходов, WARP-проксирования и LAN-исключений, чтобы исключить утечки трафика и поверхность атак локальных прокси.

---

## Ключевые возможности

### Незаметность для ТСПУ / DPI (AmneziaWG 3.1)
- **Порт `443/udp` по умолчанию:** маскировка под легитимный HTTP/3 (QUIC) трафик, с автоматическим выбором случайного порта `20000-59999/udp`, если `443/udp` уже занят.
- **QUIC v1 Initial мимикрия (`I1`):** генерируется CPS-шаблон в формате RFC 9000 QUIC v1 Initial (`<b 0xcX0000000108><r 8><b 0x00004xxx><r 200..340>`) вместо исходящих DNS-пакетов.
- **Профиль обфускации 3.1:** `HeaderProtectionKey` (шифрование заголовков), `ContentPaddingAddition = 32-128`, `Jc = 3..5`, `Jmin = 40..79`, `Jmax = Jmin + 50..160`, а также `S1..S4 >= 12` с математической защитой от коллизий длин пакетов (`S1+56 != S2`, `S2+28 != S3`, `S1+84 != S3`, проверка `s4_collides`).
- **Защита от active probing (`DisableCookies = on`):** автоматически включается на сервере, если поддерживается установленными ядром и `amneziawg-tools`.
- **Чистый IPv4 full-tunnel (`0.0.0.0/0`):** без IPv6-утечек и известных проблем клиента на `::/0`.

### Автоматическая ротация и подписки (TSPU Defense & Zero-Downtime Updates)
- **Бесшовная ротация сервера (`rotate`):** смена UDP-порта (`20000-59999`), приватных/публичных ключей сервера и клиента, а также всех параметров обфускации (`HPK`, `I1`, `S1..S4`, `Jc`, `Jmin..Jmax`).
- **Сохранение идентичности клиентов:** имена клиентов, внутренние IP-адреса и постоянные токены доступа сохраняются при любых ротациях.
- **Встроенный шедулер (`awg-rotate.timer`):** автоматическая ротация по расписанию (каждые 3 дня в 04:00, еженедельно или ежедневно) через нативный systemd timer.
- **HTTP Subscription API (`awg-api.service`, порт 8443):** легковесный API-сервер (без внешних зависимостей) для автоматической доставки обновлённых конфигураций клиентам по постоянному секретному токену:
  - Формат `.conf` (`/sub/<token>`) — готовый файл конфигурации AmneziaWG.
  - Формат `vpn://` (`/vpn/<token>`) — ссылка формата AmneziaVPN для импорта в один клик.
  - Формат JSON (`/sub/<token>?format=json`) — структурированный манифест с параметрами и base64-конфигом.
  - Формат RouterOS `.rsc` (`/rsc/<token>`) — скрипт конфигурации для MikroTik RouterOS.
  - **Кэширование ETag / 304 Not Modified:** клиенты и роутеры опрашивают сервер с заголовком `If-None-Match`; если ротации не было, сервер возвращает пустой ответ `304`, экономя трафик и ресурсы.
  - **Защита от перебора (Brute-force protection):** скользящее окно 60 запросов/мин, автоматический бан при сериях 403 Forbidden.

### Безопасность и надёжность сервера
- **Изоляция и права доступа:** `umask 077`, каталог `/etc/amnezia/amneziawg` с правами `700`, конфиги и QR-коды с правами `600`, файл учётных данных `/root/awg-credentials.txt` с правами `600`.
- **Защита от гонок (`flock`):** операции изменения конфига, клиентов и бэкапов блокируются через `/run/lock/awg-manager.lock`.
- **Sysctl hardening (`/etc/sysctl.d/99-awg-hardening.conf`):** `ip_forward=1`, `rp_filter=2`, запрет ICMP redirects и source routing, включение `tcp_syncookies=1`.
- **Валидация сети и имён:** случайная подсеть `10.x.y.0/24`, строгая проверка клиентских имён (`^[A-Za-z0-9_-]{1,32}$`, запрет зарезервированных имён), отсеивание приватных/CGNAT IPv4 при автоопределении внешнего адреса, безопасные `tar`-бэкапы и восстановление без path traversal / спецфайлов.
- **Hardening systemd для бота:** `NoNewPrivileges=yes`, `PrivateTmp=yes`, `ProtectHome=yes`, `ProtectKernelModules=yes`, `RestrictSUIDSGID=yes`, `LockPersonality=yes`, `RestrictAddressFamilies=AF_INET AF_INET6 AF_NETLINK AF_UNIX`.

## Быстрая установка

Запустите на чистом VPS с **Ubuntu 24.04 LTS** от имени `root`:

```bash
curl -fsSL https://raw.githubusercontent.com/aligorov/awg-3xui-installer/main/install.sh | sudo bash
```

Или локально из клонированного репозитория:

```bash
sudo bash install.sh
```

По завершении установки вы получите конфиг `/etc/amnezia/amneziawg/client1.conf`, QR-код для мобильного приложения и установленную команду `awg-manager`.

### Параметры через переменные окружения

При первом запуске `install` (или при `reinstall`) можно переопределить настройки:

| Переменная | По умолчанию | Описание |
| :--- | :--- | :--- |
| `AWG_PORT` | пусто (`443/udp`, иначе `20000-59999`) | UDP-порт сервера (`1..65535`) |
| `AWG_SUBNET` | пусто (случайная `10.x.y.0/24`) | Приватная подсеть клиентов в формате `/24` (например `10.66.66.0/24`) |
| `AWG_ENDPOINT` | пусто (автоопределение внешнего IPv4) | Внешний IP или домен для клиентских конфигов |
| `AWG_DNS` | `1.1.1.1, 9.9.9.9` | DNS-серверы для клиентов |
| `AWG_MTU` | `1280` | MTU туннеля |
| `AWGM_PLAIN` | `0` | `1` — отключить ANSI-цвета и `tee`-логирование (удобно для запуска из скриптов/бота) |

Пример неинтерактивной установки с заданным портом и подсетью:

```bash
sudo AWG_PORT=443 AWG_SUBNET=10.77.77.0/24 bash install.sh install
```

## Интерактивное меню (`awg-manager`)

После установки выполните в терминале:

```bash
sudo awg-manager
```

Доступные разделы меню:
- **УПРАВЛЕНИЕ КЛИЕНТАМИ:**
  1. Список клиентов, статус онлайн, трафик (`↓TX / ↑RX`) и вывод QR-кода в консоль
  2. Добавить нового клиента
  3. Удалить клиента
  4. Постоянный токен клиента и ссылки подписки (HTTP API)
- **СЕРВИС И МОНИТОРИНГ:**
  5. Настроить Telegram-бота (токен, статус, перезапуск)
  6. Ротация сервера (смена порта, ключей и обфускации AWG 3.1)
  7. Авто-ротация по шедулеру (таймер `systemd`)
  8. Детальный статус и статистика
  9. Перезапустить туннель (`awg-quick@awg0`)
- **ОБСЛУЖИВАНИЕ:**
  10. Резервная копия (`backup`) / Восстановление (`restore`)
  11. Переустановить AmneziaWG начисто (с предварительным бэкапом и перегенерацией ключей)
  12. Полное удаление AmneziaWG
  13. Самодиагностика — проверка модуля ядра, параметров 3.1, порта, NAT/UFW, `rp_filter` и handshake
  14. Перехват входящих пакетов 15с (`diagnose-live`) — тест прохождения UDP-пакетов до VPS (без записи файлов в `/tmp`, совместимо с AppArmor Ubuntu 24.04)

## Telegram-бот управления (`bot.py`)

Бот написан на чистом Python 3 (без сторонних pip-зависимостей), форматирует ответы через безопасный HTML (`html.escape`) и автоматически редактирует токен в логах.

### Модель доступа (Fail-Closed)
Переменные хранятся в `/etc/amnezia/amneziawg/bot.env` (`chmod 600`):
- `BOT_TOKEN` — токен от `@BotFather`
- `ADMIN_ID` — один или несколько числовых Telegram User ID через запятую (если пусто или невалидно — бот завершается с ошибкой, доступ закрыт)
- `GROUP_ID` *(опционально)* — ID разрешённой группы / супергруппы
- `TOPIC_ID` *(опционально)* — ID разрешённого топика в супергруппе (включая строгую блокировку General-топика, если указан `TOPIC_ID`)

Настройка через меню или CLI:

```bash
sudo awg-manager bot
```

### Команды бота
- `/start`, `/menu` — главное меню управления с быстрыми кнопками (`📋 Клиенты`, `➕ Добавить`, `🔄 Ротация`, `⏱ Авто-шедулер`, `📊 Статус`, `🩺 Диагностика`)
- `/clients`, `/list` — список клиентов, статус рукопожатия, трафик, кнопки `QR`, `🔑 Токен` и `🗑 Удалить`
- `/token [имя]` — вывод постоянного токена, ссылок подписки (`.conf`, `vpn://`, `JSON`, `.rsc`)
- `/rotate` — интерактивный запуск немедленной ротации сервера (с подтверждением)
- `/schedule` — меню настройки расписания авто-ротации (Каждые 3 дня, Раз в неделю, Раз в сутки, Отключить)
- `/add [имя]` — создать клиента (имя `A-Za-z0-9_-`, 1–32 символа) и сразу получить `.conf` и QR-код
- `/qr <имя>` — получить `.conf` и QR-код существующего клиента
- `/status` — состояние сервиса, порт, активные пиры и трафик
- `/diagnose` — запуск серверной самодиагностики прямо из Telegram
- `/cancel` — отмена ожидания ввода имени клиента (также действует автотаймаут состояния `600` секунд)
- `/id`, `/topic`, `/chatid`, `/thread` — служебная команда (только для `ADMIN_ID`) для получения `chat_id`, `thread_id` и User ID

## Автоматическое обновление в MikroTik (Контейнер AmneziaWG)

Интеграция идеально работает с проектом [`routeros-aligorov/amneziawg-mikrotik`](https://github.com/aligorov/amneziawg-mikrotik).

При блокировке UDP-порта или параметров ТСПУ нет необходимости вручную перенастраивать RouterOS или пересоздавать файлы:

1. **Генерация токена:** при создании клиента (например, `mikrotik`) сервер генерирует постоянный секретный токен `awg_tok_...`.
2. **Адрес подписки:**
   ```
   http://YOUR_SERVER_IP:8443/sub/awg_tok_...
   ```
3. **Легковесный Watchdog внутри контейнера AmneziaWG на MikroTik:**
   Скрипт проверяет активность рукопожатия (`latest-handshake`) и при необходимости опрашивает API с поддержкой кэширования `ETag`:

```bash
#!/bin/sh
CONF="/etc/amnezia/amneziawg/awg0.conf"
ETAG_FILE="/etc/amnezia/amneziawg/.etag"
SUB_URL="http://YOUR_SERVER_IP:8443/sub/YOUR_CLIENT_TOKEN"

LAST_ETAG=""
[ -f "$ETAG_FILE" ] && LAST_ETAG=$(cat "$ETAG_FILE")

HTTP_CODE=$(curl -s -w "%{http_code}" \
  -H "If-None-Match: \"$LAST_ETAG\"" \
  -o /tmp/awg0.conf.new \
  -D /tmp/headers.txt \
  "$SUB_URL")

if [ "$HTTP_CODE" = "200" ] && [ -s /tmp/awg0.conf.new ]; then
  NEW_ETAG=$(grep -i '^etag:' /tmp/headers.txt | awk '{print $2}' | tr -d '\r"')
  mv /tmp/awg0.conf.new "$CONF"
  echo "$NEW_ETAG" > "$ETAG_FILE"
  echo "[+] Config updated from subscription API (ETag: $NEW_ETAG). Restarting awg0..."
  awg-quick down awg0 2>/dev/null
  awg-quick up awg0
elif [ "$HTTP_CODE" = "304" ]; then
  # Конфигурация не изменилась, трафик не расходовался
  rm -f /tmp/awg0.conf.new /tmp/headers.txt
fi
```

При срабатывании таймера авто-ротации на сервере или при вызове `/rotate` в Telegram-боте контейнер на MikroTik автоматически применит новый порт, ключи и заголовки обфускации без участия администратора.

## Совместимость клиентов

Для подключения используйте официальные приложения с поддержкой **AmneziaWG 3.1**:
- **AmneziaVPN** (версия **>= 5.0.1.5**) — Windows, macOS, Linux, iOS, Android.
- **AmneziaWG** (актуальная версия с поддержкой `HeaderProtectionKey` и `ContentPaddingAddition`).

При импорте `.conf` или сканировании QR-кода весь трафик устройства пойдёт через защищённый туннель `0.0.0.0/0`.
